# Gateway dependency notices

`THIRD-PARTY-NOTICES.txt` is generated by **cargo-about 0.9.3** from the
locked Cargo workspace. It includes full dependency licence texts and
crate names/versions for the Linux amd64 and arm64 gateway builds.
Development-only dependencies are excluded; build and transitive dependencies
are retained. SigRift's own licence remains in the root `LICENSE`.
The configuration uses cargo-about's hash-checked clarifications for
concatenated AWS-LC licences and licences omitted from published crate
packages, retaining their upstream copyright notices.

The gateway image and binary release tarball ship this file. Generation is
separate from image builds so builds do not install or compile a reporting
tool. `manifest.json` records hashes of the dependency lockfile, manifests,
configuration, template, generator, and generated notice text.
`SHA256SUMS` lets the Docker builder check those files with its existing
`sha256sum` command; the offline Python check also validates this checksum list.

Check freshness without Rust, network access, or third-party Python packages:

```bash
python3 scripts/gateway-notices.py --check
```

After changing Cargo dependencies, manifests, or notice-generation inputs:

```bash
cargo install cargo-about --version 0.9.3 --locked
python3 scripts/gateway-notices.py --generate
python3 scripts/gateway-notices.py --verify-generated
```

Review and commit the regenerated notice text, `manifest.json`, and `SHA256SUMS` alongside
the dependency changes. `--locked` prevents resolution from rewriting
`Cargo.lock`; `--fail` rejects dependencies whose licensing cannot be
determined. Do not update only the recorded hashes to bypass regeneration.
`CARGO_ABOUT` may point to a separately installed executable of the same
pinned version.
