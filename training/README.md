# Training tooling

In-repo tooling for training the SigRift community edge classifier.

## Layout

```
training/
├── configs/        # YAML / JSON training configs (gitignored except .gitkeep)
├── logs/           # per-run train logs (gitignored)
├── models/         # output checkpoints + ONNX exports (gitignored)
├── tmp/            # scratch + pregen data dirs (gitignored)
├── train_open_default.py    # main training script (DDP-aware)
└── README.md       # this file
```

## Open-source default classifier

16-class focused TSCM-oriented set, family-level collapse. See
`src/sigrift/lib/taxonomy_open.py` for the canonical class list and
the collapse map (45 of the generator's 76 signal types → 16 classes).
The model is `EdgeRFClassifier` (~420K params with the 16-class head,
ONNX-exportable, target: RPi 5 / onnxruntime CPU).

## Multi-GPU training

Training is launched via `torchrun` for `DistributedDataParallel`:

```bash
torchrun --standalone --nproc_per_node=2 \
    training/train_open_default.py \
        --epochs 200 --batch-size 256 \
        --train-samples 100000 --val-samples 20000 \
        --output-dir training/models \
        --log-dir training/logs
```

Rank-0 owns checkpoint saves and ONNX export; other ranks compute
forward/backward and all-reduce gradients.

## Outputs

Each run writes:
- `training/logs/train_<timestamp>.log` — full training log
- `training/models/<run-name>_<timestamp>.pth` — last + best epoch
- `training/models/<run-name>_<timestamp>.onnx` — exported edge model
- `training/models/<run-name>_<timestamp>_metadata.json` — class
  list, collapse map, input shape, training config, GPU process count,
  epochs completed, training time, licence, git SHA at training time.
  Evaluation results are not written by this script.

## What ships in releases

Model weights are published separately from code releases, in the
`v0.1.0-models` release: the ONNX model, its PyTorch checkpoint (`.pth`)
and metadata JSON, plus the MIT `LICENSE`, a `MODEL-NOTICE.txt` and a
`SHA256SUMS` file covering the three model files. The model release is
not signed; the code-release workflow signs only code releases. The repo
carries no model weights; reproducibility lives in the training tooling
itself.

## Model weights license

The community model weights (`.onnx`/`.pth`) are licensed **MIT**,
matching the source. This training script uses synthetic IQ generated by
`signal_factory`, without a third-party dataset. New exports record
`"license": "MIT"` in their `_metadata.json` sidecar.

The `v0.1.0-models` files predate that metadata field, so its
`_metadata.json` has no licence key; the release's `LICENSE` and
`MODEL-NOTICE.txt` cover them. Future model releases should ship the
licence, metadata, checksums and signatures together, and publish revised
artifacts with new checksums instead of silently replacing existing ones.
