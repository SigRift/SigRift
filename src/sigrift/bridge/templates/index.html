    Scanner-host checks and safe retry

    On the scanner host, a read-only hardware selection plan is python3 scripts/scanner_setup.py plan --scanners=auto. It checks supported adapters, driver/permission readiness and protected network interfaces; it does not start scanners.

    For an existing managed installation, rerun ./scripts/quickstart.sh without new selection flags. It preserves saved scanner selection and operator configuration, and reports conflicts for review. Hardware is not silently selected for a saved dashboard-only installation.

    For a first hardware selection, review the operations guide before using --scanners=auto or an explicit selection. Never repurpose wlan0 or the SSH/management radio without a separate recovery path. No hardware or privilege-changing command runs from this page.

    Stored timestamps are supplied by capture records; an hourly RF summary has hour precision. They are not gateway arrival times or a liveness signal. This checklist reports SDR and Wi-Fi capture. First setup and ordinary retries send a sanitized host readiness check, when the installed node key and gateway are available. After five minutes it is labeled stale, not offline; there is no background host refresh in this version. A healthy capture lease remains independent evidence. Explicit dashboard-only setup does not probe hardware.
